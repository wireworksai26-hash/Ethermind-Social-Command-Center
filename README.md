# Ethermind Social Command Center

Multi-brand social media monitoring and analytics dashboard for **Ethermind Agency** (`ethermind.agency`) and **Klozer** (`klozer.my.id`), built with Next.js 15, PostgreSQL, Redis + BullMQ, Better-Auth, and OGL WebGL.

## Features

- **Multi-Brand Workspace Switcher:** Instant switching between `All Brands`, `Ethermind`, `Klozer`, and any additional brands created by a Super Admin.
- **Cross-Platform Analytics (5 Platforms):** Unified KPIs (Total Reach / Views, Weighted Engagement Rate, Net Follower Growth, Published Content), multi-series trend charts (by total, platform, or brand), and period-over-period comparisons (`7D`, `30D`, `90D`, `Custom`).
- **Content Leaderboard & Plasma Detail Panel:** Searchable, filterable, and sortable post leaderboard with automatic **Viral Spike** detection ($\ge 2\times$ account average) and a 60fps spring-animated detail drawer featuring 48-hour view velocity charts.
- **Hybrid Data Adapter (`ISocialPlatformAdapter`):**
  - `MetaGraphLiveAdapter` for live Instagram Business & Facebook Page metrics via Meta Graph API.
  - `DeterministicMockAdapter` for seeded, consistent sample data on pending platforms (`TikTok`, `X`, `Threads`) until developer app review completes.
- **In-App Brand, Account & Token Management:** Super Admins can create new brands, add social accounts, and configure encrypted (`AES-256-GCM`) API credentials directly from `/accounts` without touching server environment variables.
- **Invite-Only RBAC (`Better-Auth`):** Only email addresses invited by a Super Admin can register at `/accept-invite`, with per-workspace roles (`brand_manager`, `analyst`, `viewer`).
- **3D WebGL Ambient Background:** Lightweight `OGL` geodesic wireframe + glowing node constellation paired with a dynamic brand-colored GLSL shader (`3D BG: On / Paused` toggle in the header).
- **CSV Export & Automated Alerts Preview:** Export filtered overview summaries and post performance to CSV, plus a v1.1 preview page for Telegram & WhatsApp alerts.

## Tech Stack

- **Frontend & API:** Next.js 15 (App Router, TypeScript), Tailwind CSS v4, Radix UI, Motion, Recharts, TanStack Query, OGL
- **Database & ORM:** PostgreSQL + Drizzle ORM
- **Queue & Cache:** Redis + BullMQ (`metrics-ingestion` every 2h, `meta-token-refresher` every 12h)
- **Authentication:** Better-Auth (email & password, invite-only hook)
- **Deployment:** Railway (`web`, `worker`, `Postgres`, `Redis`)

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```
2. Copy `.env.example` to `.env` and fill in `DATABASE_URL`, `BETTER_AUTH_SECRET`, `TOKEN_VAULT_MASTER_KEY` (64 hex chars), and `SEED_SUPER_ADMIN_EMAIL`.
3. Run database migrations and seed initial workspaces/accounts:
   ```bash
   npm run db:migrate
   npm run db:seed
   ```
4. Start the web app and (optionally, if `REDIS_URL` is configured) the background worker:
   ```bash
   npm run dev
   npm run worker
   ```

## Railway Deployment

The production environment runs 4 services in one Railway project:
1. **Postgres** & **Redis** (managed templates, connected via `${{Postgres.DATABASE_URL}}` and `${{Redis.REDIS_URL}}`).
2. **web**: Build `npm run build`, pre-deploy `npm run predeploy`, start `npm run start`, healthcheck `/login`.
3. **worker**: Build `npm run build`, start `npm run worker`.

Required environment variables on both `web` and `worker`:
- `DATABASE_URL`, `REDIS_URL`
- `BETTER_AUTH_SECRET`, `BETTER_AUTH_URL`
- `TOKEN_VAULT_MASTER_KEY` (32 bytes / 64 hex chars)
- `SEED_SUPER_ADMIN_EMAIL`
- Optional for OAuth flow: `META_APP_ID`, `META_APP_SECRET`, `META_GRAPH_VERSION`
